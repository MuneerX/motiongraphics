## 🛠️ Deterministic Architecture & Render Pipeline

1. **Pure Time Function (`renderThreeAt(t)`):**
   * Eliminates `requestAnimationFrame` and `clock.getDelta()` drift during headless frame capture.
   * Every particle position, card coordinate, and mesh opacity is calculated as a pure mathematical function of time `t`.

2. **Dual-Mode Shell (Studio Preview & Clean Broadcast):**
   * **In Browser:** Displays interactive Studio Shell with playback transport controls, real-time timecode readout, scene jump pills, audio mute/unmute, and responsive 16:9 canvas scaling.
   * **In Headless Render (`render.mjs` / Chrome CDP):** Automatically activates `body.headless-render`, hiding all studio chrome and providing the clean 1920×1080 canvas for lossless capture.

3. **Audio Synchronization:**
   * Includes the exact soundtrack extracted from the original film (`audio.wav`).
   * Seamlessly muxed into the output MP4 during rendering.

## 🚀 How to Run & Render

### 1. Interactive Preview in Browser
Open `index.html` directly in Google Chrome, Microsoft Edge, or any modern web browser:
```bash
start outship_recreation/index.html
```

### 2. Render Full 53.4s MP4 with Audio
```bash
node "../.agents/skills/motionmaxxing/scripts/render.mjs" index.html outship_recreation_master.mp4 --fps 30 --crf 18 --audio audio.wav
```
